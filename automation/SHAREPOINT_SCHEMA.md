# Optional SharePoint list contract

Design only. Create columns with these exact names **initially** so internal names match. Use no spaces. Keep the lists in the same test site. All listed text columns are single-line text except Detail. Using plain text for status/priority makes the formulas and trigger expression simple; required fields and allowed values must be validated in the app and restricted for other writers if used beyond a demo.

| List | Column | SharePoint type / rule |
| --- | --- | --- |
| `ServiceTickets` | `ID` | Built-in numeric unique ID, generated by SharePoint; don't Patch it on creation |
| | `Title` | Built-in text, required; short ticket summary |
| | `OrderId` | Text, required, indexed; matches OrdersReference.OrderId |
| | `CreatedDate` | Date only, required; business ticket date, distinct from SharePoint's Created timestamp |
| | `ClosedDate` | Date only, optional |
| | `Category` | Text, required: Damage / Missing parts / Assembly / Warranty |
| | `Priority` | Text, required: High / Medium / Low |
| | `TicketStatus` | Text, required, default Open: Open / Closed; indexed |
| `OrdersReference` | `Title` | Text: use same value as OrderId for easy viewing |
| | `OrderId` | Text, required, **enforce unique values** (indexed) |
| | `OrderDate` | Date only, required |
| `ServiceNotificationLog` | `Title` | Text, required; run name plus outcome, not a unique-send guarantee |
| | `TicketId` | Number, zero decimals |
| | `RunId` | Text |
| | `Outcome` | Text: Sent / Failed |
| | `LoggedAt` | Date and time, UTC |
| | `Detail` | Multiple lines plain text; no secrets |

Populate OrdersReference with a **small test subset** of known, dated orders (for example 20) from the cleaned Orders query: map order_id to OrderId and order_date to OrderDate. Do not import the dirty CSV blindly; it has duplicates and a missing date. This is a test design, not a provided list deployment. ServiceTickets starts empty so you can see app submissions and flow triggers clearly. The Power Apps example uses the list names above as data source names.
